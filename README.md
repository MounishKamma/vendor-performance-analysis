# Vendor Performance Analysis

## Project Overview
A complete end-to-end data analytics project analyzing vendor performance 
for a liquor retail chain with 80 stores across multiple cities.

## Dataset
- 12M+ rows of real-world sales and inventory data
- 6 datasets: Sales, Purchases, Inventory, Vendor Invoices, Purchase Prices
- Time period: 2024 (Full Year)

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQL (SQLite)
- Tableau (Dashboard)

## Key Findings
- Total Sales Revenue: $452M with 28.79% profit margin
- CONSTELLATION BRANDS is the best performing vendor
- December is the highest sales month ($52.3M)
- Store 76 is the top performing store ($25.4M)
- Business inventory grew 17% in value during 2024

- vendor_analysis.ipynb — Main analysis notebook
